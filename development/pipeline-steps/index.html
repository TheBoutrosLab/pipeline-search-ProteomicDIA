Pipeline Steps

write_MSFraggerParams creates a native fragger.params file from params.MSFragger and the decoy prefix. search_database_MSFragger runs the supplied JAR on each mzML with the target-decoy FASTA, producing a PIN file and one or more pepXML files (including _rankN.pepXML files in DIA mode). convert_pepXML2idXML_MSFragger uses PepXMLs2IdXML.py and pyOpenMS 3.5.0 to combine the pepXML ranks for each fraction. Each PeptideIdentification records the source mzML as file_origin, its fraction label, MSFragger rank, and source pepXML filename. merge_idXML_MSFragger combines fractions into one protein identification run per sample while preserving those PSM annotations.

calculate_SHA512 writes a checksum sidecar for every pepXML rank, PIN file, per-fraction idXML, and merged idXML.
